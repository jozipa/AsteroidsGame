# ☄️ Asteroids Clone

A web-based recreation of the classic arcade game "Asteroids", built from scratch using TypeScript. 
This completed project focuses on implementing core game loop mechanics, custom 2D physics, 2d collisions and efficient graphics rendering without the use of heavy game engines.


## 🛠 Tech Stack
* **Language:** TypeScript
* **Rendering:** HTML5 Canvas API
* **Graphics:** Spritesheet Mapping

## ✨ Key Features
* **Zero-Gravity Physics:** Custom implementation of velocity, acceleration, and inertia, allowing the ship to "drift" realistically in space.
* **Spritesheet Rendering:** Efficient mapping and drawing of all game assets (ship, asteroids, effects) from a single image file.
* **Collision Detection:** Accurate 2D hitboxes and collision logic between the player, projectiles, and asteroids of varying sizes.
* **Fully Typed:** Written entirely in strict TypeScript for better error handling and code maintainability.

## 💻 How to Run Locally
Since this project uses TypeScript, it requires Node.js to install dependencies and compile the code.

1. Clone the repository: `git clone [your_repo_link]`
2. Navigate to the project folder and install dependencies:
   `npm install`
3. Start the local development server (or compile the code):
   `npm run dev` 
   *(Note: adjust the command above if you used a different script like `npm start` or `npm run build`)*
